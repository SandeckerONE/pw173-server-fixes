# 7. Instances that won't open
✅ *[tested]*

The package ships with only `gs01` and `is61` set to `yes` in `/opt/maps`, so most dungeons give "Can't enter instance". Set the ones you need to `yes` (see [section 6](06-lag-and-login-bounces.md) for the CPU cost) and restart. Secret Passage is `is02`, Hall of Deception `is08`.
